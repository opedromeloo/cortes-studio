cortes-studio — Privacy Policy & Terms

cortes-studio is a private tool used only by the owner of the YouTube channels Arroba Cortes, Famoso Contou, Craque Contou and Milhão Contado to manage their own videos (upload metadata, scheduling, descriptions, comments and channel analytics) through the YouTube API Services.

Data accessed: only data of the channels owned by the operator, via Google OAuth (YouTube Data API and YouTube Analytics API). The tool does not collect data from other users, does not sell or share any data with third parties, and stores access tokens only on the owner's own computer.

Terms: the tool is provided as is, for the owner's personal use only.
